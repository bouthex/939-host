# Código de conducta

939 Host es un proyecto hecho entre amigos y abierto a cualquiera. Esperamos que todas las personas que
participen (issues, pull requests, discusiones) lo hagan con respeto.

- Tratá a los demás con amabilidad y paciencia; criticá ideas y código, no personas.
- No se toleran insultos, acoso, discriminación, amenazas ni publicar datos privados de otras personas.
- Mantené las conversaciones en el tema del proyecto.

Los mantenedores pueden editar o borrar comentarios y bloquear a quien no respete estas pautas.
Para reportar un problema de conducta, escribí en privado a los mantenedores a través del perfil de
GitHub de [@bouthex](https://github.com/bouthex).
